Project Overview

EmployEase is a React and Django-based employee management application. It provides HR administrators with employee management functionality and employees with their own dashboard. The application uses REST APIs to connect the frontend and backend.

Key Features

  • Separate HR Admin and Employee dashboards
  • Employee creation, viewing, updating and deletion
  • REST API integration using Django REST Framework
  • Role-based access and authentication

  • Responsive React user interface
